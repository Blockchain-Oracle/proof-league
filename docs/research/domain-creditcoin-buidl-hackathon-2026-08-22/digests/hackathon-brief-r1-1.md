# Digest: hackathon-brief (round 1)

**Summary:** The live event as of 2026-08-22 is BUIDL CTC 2026 Fall — "BUIDL For The Real World", hosted on DoraHacks (https://dorahacks.io/hackathon/buidl-ctc-2026-fall/detail), sponsored by Creditcoin & Credit Labs, running Aug 13 – Sep 6, 2026 with winners announced Sep 18, 2026. The season theme is a hard gate, not a track: every submission must meaningfully and functionally integrate the Attestcoin Protocol, which is explicitly the rebrand of Universal Smart Contracts (USC) — "The Attestcoin Protocol was previously introduced under the name Universal Smart Contracts (USC)." Five tracks (DeFi, RWA, DePIN, Gaming, and a newly added AI track) compete for one shared $15,000 pool ($10k/$3k/$2k), plus CertiK audit credits for all winners and a CEIP fast-track (direct-to-due-diligence for Credit Labs' $10M investment program, $25k–$250k range) for the top three. Submission requires a public GitHub repo with README, a deck/whitepaper PDF, a prototype demo video, an Attestcoin integration summary, original work built during the hackathon, and deployment on a testnet; minimum team size is 1. No weighted judging rubric or judges list is published anywhere official — the only stated criterion is that "depth of Attestcoin Protocol utilization will be evaluated as one of the core scoring criteria." The prior Spring 2026 edition (Feb 1 – Mar 7/8, 76 BUIDLs, 189 hackers, same $15k pool) was won by CrediKye (on-chain ROSCA savings circles), HashCredit (BTC mining payouts → on-chain USDT credit lines via USC), and SnowBall (CDP/lending/DEX/yield rails for Creditcoin RWA).
