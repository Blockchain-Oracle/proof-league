# Digest: hackathon-brief (round 2)

**Summary:** The official Kickoff AMA (youtu.be/HPL6LjTqQm4), transcribed this run from YouTube's own captions, closed nearly every round-1 gap. Judging criteria ARE named — the five CEIP pillars (user base expansion, technical alignment, product vision, execution capability/team track record, market and technical relevance), stated verbatim as "not only the core criteria for CEIP, but also this hackathon" and repeated in Q&A as what judges look for; no numeric weights exist. Open source IS mandatory ("Yes, it needs to be open source") plus an explicit expectation of incremental transparent commits rather than one end-of-window dump — but no license is named. The deadline is authoritatively September 6, 2026, 11:59 PM ET (stated twice), with winners announced Sept 18. The biggest NEW architectural constraint: writability is explicitly out of scope for the hackathon — readability only — so any product whose core loop requires Creditcoin to cause an action on Ethereum is dead; outbound legs must be conventional RPC. Supported source chains are Ethereum only (testnet chainKey 1 = Sepolia, chainKey 3 = Ethereum mainnet); no Bitcoin, no Solana. The provable surface is transaction inclusion only (Merkle + continuity proof, returning raw ABI-encoded tx bytes), verified synchronously in-transaction, with a documented MUST-check on the tx status field since inclusion does not imply execution success.
