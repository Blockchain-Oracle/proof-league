# Digest: landscape (round 1)

**Summary:** Creditcoin's cross-chain verification layer has TWO official names for one thing: the docs now call it the "Attestcoin Protocol" and state plainly that it was "formerly called USC", while the company's own June 2026 mainnet announcement and every active Gluwa repo still say "Universal Smart Contracts (USC)" — plus "CCNext" appears in repo descriptions. So Attestcoin IS a genuine Creditcoin/Gluwa product name, not a community coinage; "attestors" are the actor role inside it. The decision-critical fact is green: as of 2026-06-18 USC readability is live on Creditcoin MAINNET, letting Creditcoin contracts read and cryptographically verify Ethereum-mainnet transaction data with no contract deployed on Ethereum and no trusted intermediary — testnet (Sepolia) had shipped 2025-09-09. Readability is explicitly the first capability on mainnet; writability was not confirmed live. Mechanically a contract calls the Block Prover Precompile at 0x0FD2 — verify() / verifyAndEmit(chainKey, blockHeight, encodedTransaction, merkleProof, continuityProof) — synchronously in one block (~15s), decoding results with EvmV1Decoder, and MUST itself check the receipt status == 0x1 because the precompile proves inclusion, not success. Creditcoin is EVM-compatible (Solidity/Vyper, Remix/Hardhat/ethers.js), mainnet chain ID 102030 and testnet "Creditcoin Testnet" chain ID 102031, native token CTC, Blockscout explorers; block time is not documented on the pages read. USC is unambiguously the 2026 flagship — the homepage brands Creditcoin "The Layer 1 Built for Cross-Chain Builders" and six USC repos were updated within the last four months, several within days of this run.

## Contradictions
- Naming is split across three official surfaces for one product: docs.creditcoin.org calls it the "Attestcoin Protocol" ("formerly called USC"), the creditcoin.org blog and all GitHub repos call it "Universal Smart Contracts / USC", and Gluwa repo descriptions call the bridge "CCNext" (USC-Builder-Examples, cc-next-query-builder). The June 2026 mainnet post contains no reference to "Attestcoin" at all and links to the legacy /creditcoin-usc docs path.
- Chain support: marketing copy says USC can query "any blockchain: Ethereum, Solana, Bitcoin, or any network with a verifiable transaction history", but architecture docs only commit to "EVM chains like Ethereum" with an "eventual goal" of any chain, and the only concretely evidenced integrations are Ethereum mainnet and Ethereum Sepolia.
- Version numbers conflict across docs pages: the docs release-notes index surfaces "Version 3.52.0-Mainnet" while the endpoints page's local-dev docker tag is gluwa/creditcoin3:3.130.0-testnet. Do not quote a Creditcoin version without re-verifying against the changelog page.
- The docs are reorganized such that URLs cited by the company's own June 2026 announcement (docs.creditcoin.org/creditcoin-usc) and by search engines (/usc, /usc/overview/usc-architecture-overview) 404 against the current /attestcoin-protocol/* tree.
