# Digest: builder-reality (round 1)

**Summary:** A small team can realistically ship a USC dApp in a hackathon window, but on a narrow, well-worn path. The official SDK (@gluwa/usc-sdk, v0.18.0, repo gluwa/cc-next-query-builder) is actively maintained with 30 releases since Oct 2025 and a decent README, and gluwa/usc-testnet-bridge-examples ships four ordered tutorials (Hello Bridge, Custom Contracts Bridging, Bridge Offchain Worker, Loan Flow) that are actually exercised by dedicated GitHub Actions workflows — the strongest positive DX signal found. EvmV1Decoder.sol and USCProofVerifier.sol do exist in gluwa/USC-Builder-Examples under contracts/UseCases/SourceDestinationLoanRecording/, alongside a complete cross-chain loan-recording use case (source registry+helper on Sepolia, destination recorder + readability manager on Creditcoin). The four real constraints are: ~8-10 minutes of attestation latency per Sepolia proof round-trip; a Discord-only CTC faucet giving 100 CTC/24h which the tutorial README says covers only ~9 oracle queries (testnet oracle fees "artificially high to prevent DOS"), with faucet.cc3-testnet.creditcoin.network confirmed to have no backend behind its DNS record; every docs.creditcoin.org/usc/* URL now 404s because the docs were rebranded to /attestcoin-protocol/*, including links inside the repo READMEs themselves; and pre-1.0 SDK churn plus four open, unanswered security issues against the example contracts. Evidence of third-party teams actually building is essentially absent — zero-to-one stars across all Gluwa USC repos, no retrievable named BUIDL CTC project or winners page, and the first edition's deadline was extended while Demo Day was downgraded to an online announcement.

## Contradictions
- Cost of an oracle query: the Hello Bridge README says 100 test CTC covers only ~9 oracle queries (~11 CTC each, 'testnet oracle fees are artificially high to prevent DOS'), while the official Gas Costs doc models verification at ~2.59×10⁻⁵ CTC for a recently-finalized transaction. Best reading: the ~11 CTC is a deliberately inflated testnet oracle/query submission fee layered on top of gas, and the Gas Costs page describes only the verification compute component (possibly at mainnet economics). Neither source cross-references the other. For hackathon planning the binding constraint is the ~9 queries per 100 CTC per 24h, not the gas math.
- Proof builder hostname: the tutorial repo .env and the SDK README both use https://prover.cc3-testnet.creditcoin.network, while the official environments doc lists https://proof-gen-api.cc3-testnet.creditcoin.network/ for the same service. Unresolved which is canonical (both DNS names exist per issue #36's host enumeration).
- Sepolia chain key: cc3-testnet uses SOURCE_CHAIN_KEY=1 for Sepolia (repo .env and docs environments table), but creditcoin-usc-networks/networks.json assigns Sepolia chainkey 3 on usc-devnet/cc3-devnet, and the docs table assigns chainkey 3 to Ethereum Mainnet on testnet. Chain keys are per-environment and must not be hardcoded from a different network's config.
