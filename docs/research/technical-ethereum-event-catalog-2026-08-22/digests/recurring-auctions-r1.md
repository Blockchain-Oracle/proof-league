# Digest: recurring-auctions

**Summary:** The anchor is broken. The Nouns daily auction is still running mechanically — contract unpaused, duration() = 86400, Noun 1999 live and ending 2026-08-23T02:29:11Z — but it has settled at 0 ETH with winner 0x0 for ~115 consecutive days, and a full-log sweep of the last 33 hours shows ZERO AuctionBid events. Cause is verified on-chain: reservePrice() = 2.8 ETH (Prop 955, April 2026) sits far above a market that was clearing at 0.4–1.0 ETH; bidding died between Noun 1884 (1.02 ETH, ~120d ago) and Noun 1898 (0 ETH, ~105d ago). So the classic "what will tonight's Noun sell for?" market now has zero uncertainty even though its proof mechanics are perfect. Lil Nouns on mainnet is terminal — last auction (7982) settled 2024-07-12 with no successor created. ENS is very much alive (~380 renewals + ~45 registrations/day) but the post-expiry Dutch-auction premium was 0 in 47 of 47 decoded registrations, and base cost only moves because of the Chainlink ETH/USD conversion. The one live, legible, genuinely price-uncertain recurring sale I could verify is the CryptoPunks native marketplace: 33 PunkBought events in ~12.5 days, 30–140 ETH, median 33.39 ETH — but ~2.6/day irregular cadence needs a void rule, ~9% of events carry value=0 from private/wrapper flows, and any single punk holder can self-deal an arbitrary print for gas. This slice produces no 5. The 2021-era mainnet auction cohort has either died or migrated to L2s.

## Candidates
### 1. Nouns DAO daily auction — clearing price — fit 2/5
- **question_example**: What will tonight's Noun sell for?
- **settlement_mechanism**: Nouns Auction House Proxy 0x830BD73E4184ceF73443C15111a1DF14e495C706, event AuctionSettled(uint256 indexed nounId, address winner, uint256 amount), topic0 0xc9f72b276a388619c6d185d146697036241880c36654b1a3ffdad07c24038d99. Answer is `amount` (data word 1); nounId in topics[1]; winner in data word 0. Same tx also emits AuctionCreated for the next Noun (topic0 0xd6eddd1118d71820909c1197aa966dbc15ed6f508554252169cc3d5ccac756ca).
- **cadence**: daily — duration() reads 0x15180 = 86400s; the settleCurrentAndCreateNewAuction pattern guarantees one settlement tx per day
- **uncertainty**: DISQUALIFYING TODAY: the answer is a constant 0 ETH. Nouns 1988–1998 all settled at amount=0 with winner=0x0000...0000, and a full-log sweep of the proxy over the last 9,990 blocks (~33h) returned only AuctionSettled(1998,0x0,0) and AuctionCreated(1999) — zero AuctionBid events. reservePrice() = 0x26db992a3b180000 = 2.8 ETH (Prop 955, Apr 2026) is above what anyone will pay; bidding died between Noun 1884 (1.02 ETH, ~-120d) and Noun 1898 (0 ETH, ~-105d).
- **manipulation**: Ironically now trivial in the *upward* direction: with zero organic bidding, one bettor holding a YES position can simply bid 2.8 ETH themselves and force any 'will it sell' market to YES for the reserve price. Outcome-makers absolutely can bet — the bidder IS the outcome. Also a governance kill-switch: the same whale coalition that set the 2.8 ETH reserve can pass a proposal calling pause() and stop the daily settlement tx entirely (paused() reads false today).
- **single_tx_settlement**: YES — one settleCurrentAndCreateNewAuction tx carries AuctionSettled with the full answer; no aggregation, and a no-bid day is still positively emitted as AuctionSettled(id, 0x0, 0) so there is no absence-proof problem.
- **live_evidence**: eth_call auction() on 0x830BD73E4184ceF73443C15111a1DF14e495C706 at block 25,813,747 returns nounId=1999, amount=0, startTime=0x6a890977 (2026-08-22T02:29:11Z), endTime=0x6a8a5af7 (2026-08-23T02:29:11Z), bidder=0x0, settled=false; paused()=false. eth_getLogs shows 11 consecutive daily AuctionSettled events (Nouns 1988–1998), all 0 ETH. Source: Ethereum mainnet JSON-RPC https://eth.drpc.org (this run).
- **notes**: Proof plumbing is textbook-perfect and worth showcasing; the uncertainty is gone. Do not ship as a price market. If Nouns must appear for narrative reasons, use it to demo the receipt pipeline and disclose both the 0-ETH streak and the pause risk.
### 2. Nouns DAO daily auction — binary 'does it get a bidder?' — fit 2/5
- **question_example**: Will tonight's Noun get any bidder at all?
- **settlement_mechanism**: Same contract/event as above; the answer is whether `winner` (data word 0) is non-zero. YES and NO are BOTH carried by the same positive settlement transaction.
- **cadence**: daily, 24h, guaranteed settlement tx
- **uncertainty**: Technically a real binary and the cleanest no-absence-proof design in the whole slice, but the observed base rate is 0 for 115 consecutive days, so the market is ~99% predictable NO and boring to trade.
- **manipulation**: Cheapest possible: a YES holder bids the 2.8 ETH reserve themselves and wins the Noun. Cost = 2.8 ETH minus the resale value of the Noun, so effective cost could be well under 2.8 ETH. Strong endogeneity — bettors can be bidders.
- **single_tx_settlement**: YES — AuctionSettled(id, winner, amount) proves both outcomes positively.
- **live_evidence**: Zero AuctionBid events (topic0 0x1159164c56f277e6fc99c11731bd380e0347deb969b75523398734c252706ea3) on the proxy across the last 9,990 blocks; 11/11 recent settlements had winner=0x0. Source: Ethereum mainnet JSON-RPC https://eth.drpc.org (this run).
- **notes**: The one salvage framing where Nouns' proof mechanics shine, but only as a long-shot lottery. Worth keeping in the back pocket as an illustration of how to encode a negative outcome as a positive settlement event.
### 3. CryptoPunks native marketplace sale — fit 3/5
- **question_example**: Will the next CryptoPunk sell for more than 35 ETH?
- **settlement_mechanism**: CryptoPunksMarket 0xb47e3cd837dDF8e4c57F05d70Ab865de6e193BBB, event PunkBought(uint256 indexed punkIndex, uint256 value, address indexed fromAddress, address indexed toAddress), topic0 0x58e5d5a525e3b40bc15abaa38b5882678db1ee68befd2f60bafe3a7fd06db9e3. Answer is `value` (data[0:32], wei); punk id in topics[1]; buyer in topics[3].
- **cadence**: irregular, ~2.6 sales/day (33 events in ~12.5 days)
- **uncertainty**: GENUINE — observed non-zero prints range 30.0 to 140.0 ETH, median 33.39 ETH, over 12.5 days. Depends entirely on which punk a human decides to buy and at what listing; not computable or simulatable in advance.
- **manipulation**: CHEAP AND ENDOGENOUS — the biggest problem. Any punk holder can offerPunkForSaleToAddress() to their own alt wallet at an arbitrary price and self-buy for ~gas, printing any settlement value they want. A bettor who owns one punk (~30 ETH capital, recoverable since they buy it back from themselves) can force nearly any over/under. Needs an outlier filter, a multi-sale rule, or an explicit self-deal exclusion — none of which are single-tx-provable.
- **single_tx_settlement**: YES — one PunkBought event carries the price. Caveat: ~9% of events (3 of 33) carry value=0 from private / wrapper flows, so the market must guard on value > 0 and void otherwise, or a fake 0 settles 'under'.
- **live_evidence**: eth_getLogs over ~90,000 blocks ending 25,813,747 returned 33 PunkBought events, most recent at block 25,813,248; examples: punk 9799 @ 115.0 ETH (blk 25791213), punk 1326 @ 51.0 ETH (blk 25803982), punk 5151 @ 38.5 ETH (blk 25804583). Source: Ethereum mainnet JSON-RPC https://eth.drpc.org (this run).
- **notes**: The only live + legible + price-uncertain recurring sale in this slice. Blocked from a 4-5 by (a) irregular sub-daily cadence requiring an explicit void rule so 'no sale today' never becomes an absence proof, and (b) wash-trade manipulability by any single punk holder.
### 4. ENS .eth registration premium (post-expiry Dutch auction) — fit 2/5
- **question_example**: What premium will the next expiring .eth name sell for?
- **settlement_mechanism**: ETHRegistrarController 0x253553366Da8546fC250F225fe3d25d0C782303b, event NameRegistered(string name, bytes32 indexed label, address indexed owner, uint256 baseCost, uint256 premium, uint256 expires), topic0 0x69e37f151eb98a09618ddaa80c8cfaf1ce5996867c489f45b555b412271ebf27. Answer would be `premium` (data word 2); `baseCost` is word 1. Legacy controller 0x283Af0B28c62C092C9727F1Ee09c02CA627EB7F5 emits the 5-arg variant (topic0 0xca6abbe9d7f11422cb6ca7629fbf6fe9efb1c621f71ce8f02b9f2a230097404f) with a single combined `cost`.
- **cadence**: ~12-25 registrations/day on the 2023 controller plus ~21/day on the legacy controller
- **uncertainty**: DISQUALIFYING: premium was exactly 0 in 47 of 47 registrations decoded over ~30,000 blocks (~4 days). Nobody is buying inside the 21-day premium window, so the field is a constant. Separately, the premium curve itself is a deterministic exponential decay in time — given the registration timestamp it is computable, so only the human choice of *when* carries information, and that information is currently never exercised. baseCost drifts (0.004857 -> 0.004851 -> 0.005616 ETH for 4-char names) purely from the Chainlink ETH/USD conversion, which is an ETH-price market in disguise and belongs to a different slice.
- **manipulation**: Anyone can register any expiring name at any moment during the premium window and set the print; cost is just the premium they choose to pay. Fully endogenous, and cheap for low-value names.
- **single_tx_settlement**: YES — one NameRegistered event carries baseCost and premium separately.
- **live_evidence**: eth_getLogs on 0x253553366Da8546fC250F225fe3d25d0C782303b over the last 7,000 blocks (~23h) returned 379 NameRenewed + 24 NameRegistered; decoding 47 NameRegistered events over ~30,000 blocks gave premium = 0 in every case (e.g. 1917.eth base=0.004857 premium=0, avataros.eth base=0.001988 premium=0, blockchainporn.eth base=0.002210 premium=0). Source: Ethereum mainnet JSON-RPC https://eth.drpc.org (this run).
- **notes**: ENS is unambiguously alive on mainnet — this fails on uncertainty, not liveness. Also note most registration volume is bot bulk-minting of 4-digit numeric names (15 registrations across 12 consecutive blocks), which is not the human behavior the product wants to price.
### 5. ENS .eth renewal cost — fit 2/5
- **question_example**: How much ETH will the next .eth renewal cost?
- **settlement_mechanism**: ETHRegistrarController 0x253553366Da8546fC250F225fe3d25d0C782303b, event NameRenewed(string name, bytes32 indexed label, uint256 cost, uint256 expires), topic0 0x3da24c024582931cfaf8267d8ed24d13a82a8068d5bd337d30ec45cea4e506ae. Answer is `cost`. BaseRegistrar 0x57f1887a8BF19b14fC0dF6Fd9B2acc9Af147eA85 emits a parallel NameRenewed(uint256 indexed id, uint256 expires).
- **cadence**: very high — 379 events in ~23h (~380/day), the highest-frequency single-tx price event found in this slice
- **uncertainty**: PARTIAL — cost = human-chosen duration (in years) x USD price schedule, converted through a Chainlink ETH/USD feed at settlement time. Both inputs are genuinely unknown in advance. But it is a hybrid of a human choice and an ETH price market, and fails the legibility bar badly: no newcomer finds 'how much ETH will the next .eth renewal cost' an interesting question.
- **manipulation**: Trivial — anyone can renew any name for any duration at any moment, at a cost of the renewal fee itself (a few dollars for a long name). Fully endogenous and among the cheapest manipulations in this catalog.
- **single_tx_settlement**: YES — one NameRenewed event carries the final cost.
- **live_evidence**: eth_getLogs on 0x253553366Da8546fC250F225fe3d25d0C782303b, last 7,000 blocks: 379 NameRenewed events, most recent within the last hour of block 25,813,747 (example tx 0xeb6c93da50f98045d1919c48c33a0be747581755174bcbd43b30a66b67e01837, status 0x1, value 0.005427 ETH). Source: Ethereum mainnet JSON-RPC https://eth.drpc.org (this run).
- **notes**: Listed for completeness as the highest-cadence live price event in the slice. Fails legibility and manipulation cost. Included because it proves ENS mainnet activity is real if a later slice wants an ENS-shaped market.

- Art Blocks / SuperRare / Foundation scheduled NFT auctions on mainnet — not probed within budget; all are curation-dependent and would fail the continuous-supply bar even if alive.
- Sky (MakerDAO) Clipper collateral auctions and other liquidation auctions — irregular and liquidation-driven, no scheduled cadence, so excluded before probing.
- Any recurring mainnet auction with a scheduled daily ending AND live price uncertainty — none found. This slice produces no demo_fit 5; the mainnet auction cohort has either died (Nouns economics, Lil Nouns) or migrated to L2s.
- Etherscan HTML pages — WebFetch returns HTTP 403 from this environment, so no Etherscan page was usable as a source; all on-chain facts were verified by direct JSON-RPC eth_getLogs / eth_call instead, which is a stronger primary source.
